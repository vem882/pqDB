## Description

# PandaQuest Database

Install PandaQuest Database alongside **[PandaQuest](https://www.curseforge.com/wow/addons/pandaquest)**
to use quest navigation, map pins, the quest browser and related tooltips in your game.

The database supplies quests and their objectives, NPCs, objects, items and zone information.
It also includes quest corrections and gathering, respawn, drop and flight data where available.

### Supported games

- Mists of Pandaria Classic
- Classic Era
- The Burning Crusade Classic Anniversary
- WoW Forever

### Installation

Install and enable **PandaQuest** and **PandaQuest Database** for the same game version.
Restart World of Warcraft after installing. Open the PandaQuest quest browser with `/pq`.

The database works locally in the game. PandaQuest Sync is optional and is used for opted-in sharing
and community guide updates. Find quest guides, maps, professions and community data on
[PandaBase](https://pd.zroot.it/).

### Source and credits

The [database repository](https://github.com/vem882/pqDB) contains the data, source credits and licence.
The quest data is based on Questie and QuestieDB. Supplemental data includes contributions from
pfQuest and PandaBase.
